# 食品寄递线索协同闭环

连接食品经营资质核验、寄递事件和跨部门风险处置。

## 领域范围

系统涉及食品协议客户、快递网点人员、邮政管理人员、市场监管人员。当前领域资料记录以下业务事实：

- 食品寄递同时受实名、验视和安检要求约束
- 首次揽件可通过专属代码核验经营资质和地址
- 监管部门之间需要信息互通、线索互移和处置互助

后续实现需要围绕这些边界组织服务：

- 资质时态核验
- 揽件事件幂等
- 风险线索分级
- 跨部门移交
- 在途影响传播

`contracts/domain.schema.json` 定义领域资料结构，`fixtures/domain.json` 提供不含真实身份信息的示例，`src/food_parcel_regulation/context.py` 负责读取并检查这些资料。

## 开发命令

- 运行测试：`python3 -m unittest discover -s tests -v`
- 编译检查：`python3 -m compileall -q src`

上述命令只读取仓库内资料，不需要连接外部业务服务。
